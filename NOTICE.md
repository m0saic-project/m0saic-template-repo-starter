# Notices

## Big Buck Bunny

`assets/media/bbb-2s.mp4` **and** `assets/media/bbb-frame-960x540.jpg` come
from **Big Buck Bunny**, (c) 2008 Blender Foundation —
<https://peach.blender.org> — licensed under
[Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
The clip is a 2-second excerpt, transcoded (scaled to 480×270, re-encoded)
from the official release at
<https://download.blender.org/peach/bigbuckbunny_movies/>; the still is a
single frame cut from that same clip. See `tools/regen-fixtures.mjs` for both
recipes.

They ship here as the corpus's real-world media fixtures — the clip for
probing / clipping / watermarking, the 16:9 still for examples that need
photographic luminance (the brand-mark PNG is square, and solid tiles have no
variety to read). Everything else in `assets/media/` is synthetic and
generated by the same script.
